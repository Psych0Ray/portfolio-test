# Project Instructions

## Handoff file (standing instruction)

Maintain [HANDOFF.md](HANDOFF.md) in this repo across every session. At the end of each session (or before ending one), update it to reflect:

- What has been done
- What is currently in progress
- What is planned/about to be done next

Keep it current — treat it as the source of truth for picking up work in a future session. Update it in place; don't create dated copies.
